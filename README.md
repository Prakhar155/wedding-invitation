# Prakhar & Shraddha - Luxury Indian Wedding Invitation

A digital Indian wedding invitation card featuring interactive animations, event schedules, dress codes, and sound integration.

## Features
- **Royal Design**: Gold foil typography, glassmorphism, floating rose petal animations.
- **Audio Synthesizer**: Built-in devotional music powered by Tone.js.
- **Responsive**: Optimised for modern mobile, tablet, and desktop screens.

## Quick Start
Open `index.html` directly in any modern web browser to view the invitation.
